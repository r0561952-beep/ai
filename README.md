# ai — русская нейросеть «вопрос → ответ», обученная с нуля

Маленькая GPT-модель (трансформер), которая **не использует никаких готовых весов**:
и токенизатор, и сама модель учатся с нуля на русских диалогах.
Модель помнит предыдущие реплики разговора (в пределах окна контекста — 256 токенов,
это примерно 2–3 короткие пары вопрос-ответ).

## Что внутри

| Файл | Что делает |
|---|---|
| `data/qa_ru.jsonl.gz` | датасет: 67 520 диалогов на русском (~14 млн токенов) |
| `prepare_data.py` | заново скачивает и собирает датасет |
| `tokenizer_utils.py` | BPE-токенизатор (8192 токена) и формат диалога |
| `model.py` | сама нейросеть (GPT, ~14 млн параметров в варианте `small`) |
| `train.py` | обучение с нуля / продолжение обучения |
| `chat.py` | чат с моделью |
| `model/model.pt` | обученные веса |
| `model/tokenizer.json` | обученный токенизатор |
| `colab_train.ipynb` | обучение на бесплатной видеокарте Google Colab |

## Данные

Открытые датасеты Ильи Гусева, лицензия **CC-BY-4.0**:
- [IlyaGusev/ru_turbo_alpaca](https://huggingface.co/datasets/IlyaGusev/ru_turbo_alpaca) — ~30 тыс. заданий/вопросов с ответами
- [IlyaGusev/ru_turbo_saiga](https://huggingface.co/datasets/IlyaGusev/ru_turbo_saiga) — ~37 тыс. многоходовых диалогов

Ответы в них сгенерированы ChatGPT, поэтому могут содержать ошибки.

## Как запустить

```bash
pip install -r requirements.txt
python chat.py                          # поговорить с моделью
python chat.py -q "Что такое фотосинтез?"
```

Обучение:
```bash
python train.py                                    # small, ~1 час на 4-ядерном процессоре
python train.py --resume --max_iters 7000          # продолжить обучение
python train.py --preset medium --device cuda      # большая модель на видеокарте
```

## Чего ожидать

Это крошечная модель, обученная за час на процессоре. Она уже пишет связным
русским языком и отвечает «в тему», но **часто ошибается в фактах** — знаний
у неё очень мало. Чтобы стало заметно лучше, нужны: больше параметров
(`--preset medium`), больше шагов обучения и видеокарта — см. `colab_train.ipynb`.
