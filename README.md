# ai — русская нейросеть «вопрос → ответ», обученная с нуля

Маленькая GPT-модель (трансформер), которая **не использует никаких готовых весов**:
и токенизатор, и сама модель учатся с нуля на русских диалогах.
Модель помнит предыдущие реплики разговора (в пределах окна контекста — 256 токенов,
это примерно 2–3 короткие пары вопрос-ответ).

## Данные

Открытые датасеты Ильи Гусева, лицензия **CC-BY-4.0**:
- [IlyaGusev/ru_turbo_alpaca](https://huggingface.co/datasets/IlyaGusev/ru_turbo_alpaca) — ~30 тыс. заданий/вопросов с ответами

Ответы в них сгенерированы ChatGPT, поэтому могут содержать ошибки.

## Как запустить

```bash
pip install -r requirements.txt
python chat.py                          # поговорить с моделью
python chat.py -q "Что такое фотосинтез?"
```

Обучение:
```bash
python train.py                                    # small, ~1 час на 4-ядерном процессоре
python train.py --resume --max_iters 7000          # продолжить обучение (из checkpoints/full.pt)
python train.py --preset medium --device cuda      # большая модель на видеокарте
```

## Результаты первого обучения

`small` (13,8 млн параметров), 3500 шагов (~2 прохода по данным), ~50 минут на 4 ядрах
процессора (bf16 + torch.compile). Ошибка (loss) на проверочных данных: 9,10 → **2,87**.

Пример (вопрос: «Как приготовить блины?»):
> Для приготовления блины нужно взять небольшую емкость. Сначала нужно разогреть
> сковороду … Затем добавить яйца и снова перемешать. … Добавьте немного соли … Готово!

**Честно:** модель уже пишет грамотным по форме русским языком, держит формат
«вопрос → ответ» и часто попадает в тему, но **смысла и фактов в ответах пока почти нет** —
на «Что такое солнце?» она уверенно отвечает ерундой. Для модели такого размера,
обученной с нуля за час на процессоре, это нормально.

## Второй цикл: + русская Википедия

`prepare_wiki.py` превращает 91 тыс. статей Википедии в 176 тыс. пар «вопрос → ответ»
(«Что такое Литва?» → вводная часть статьи), ~91 млн токенов. Модель дообучена
на смеси 70 % Википедии + 30 % диалогов, 6462 шага, ~1 ч 50 мин на процессоре:

```bash
python prepare_wiki.py
python train.py --init_from model/model.pt --mix wiki=0.7,qa=0.3 --lr 6e-4 --min_lr 6e-5 \
                --warmup 300 --max_iters 6500 --max_minutes 112
```

| | до | после |
|---|---|---|
| ошибка на Википедии | 4,57 | **2,95** |
| ошибка на диалогах | 2,89 | **2,76** |

**Честно:** модель научилась отвечать в стиле энциклопедии («X — это …, расположен …,
родился в …»), но **факты выдумывает**: «Пушкин — американский математик, род. 1958»,
«Луна — город в Донецкой области». В 14 млн параметров просто не помещаются знания
из 91 тыс. статей — нужна модель в разы больше и видеокарта.

## Как сделать её умнее

1. **Видеокарта + модель побольше** — `colab_train.ipynb` или Kaggle (`--preset medium`, ~40 млн параметров).
2. **Больше Википедии** — `python prepare_wiki.py --files 6` (в 3 раза больше статей; имеет смысл только для модели побольше).
3. **Взять готовую открытую модель** (например, Qwen2.5) — ответы почти как у ChatGPT, но уже не «с нуля».
